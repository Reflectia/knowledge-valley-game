# Спадок у Долині Знань — браузерна піксельна RPG

## Джерела правди
- **ТЗ:** `ТЗ RPG «Спадок у Долині Знань».md` — геймдизайн, стек, MVP і критерії приймання. Прочитай повністю перед будь-якою роботою.
- **Дизайн-система:** `design-system/README.md` — кольори, шрифти, масштаб, контраст, правила асетів. Деталі компонентів — у `design-system/components/<Назва>/README.md`.
- **Асети:** `images/` (опис — `images/README.md`).
- Якщо чогось немає в ТЗ чи дизайн-системі — запитай, не вигадуй.

## Як працювати
- **Спершу план.** Прочитай ТЗ і дизайн-систему та запропонуй план етапів. Код пиши лише після того, як я погоджу план; кожен наступний етап — теж після погодження.
- **Мова:** відповідай мені українською. Код, назви, коментарі та повідомлення комітів — англійською.
- **Git:** ініціалізуй репозиторій і роби коміт після кожного завершеного кроку.

## Стек (з ТЗ, розділ 9)
Vite + TypeScript, Phaser 3 (світ), React поверх полотна Phaser (інтерфейс), Zustand (спільний стан), карти Tiled (JSON), IndexedDB через idb-keyval + експорт/імпорт `.json`, PapaParse (CSV), SheetJS (XLSX), i18next (uk, en). Запуск — `npm run dev`, хостинг — GitHub Pages. Цільові браузери: останні Chrome, Edge, Firefox; екран від 1280×720.

## Інтерфейс
- Стилі — `design-system/tokens.css` (CSS-змінні) і `design-system/components/bundle.css` (класи `dv-*`, рамки — вбудовані 9-slice спрайти). React-компоненти обгортають ці класи; кольори й розміри — лише з токенів.
- Шрифти — `design-system/fonts/`: Press Start 2P (заголовки, числа) і Tiny5 (текст).
- Одна тема: освітлення дня й ночі діє лише на світ, не на панелі.
- Контраст тексту — WCAG AA; перевірені пари — у розділі «Контраст» `design-system/README.md`. Нові пари кольорів перевіряй так само.

## Асети
- Масштабуй лише цілими кратними, без згладжування: у Phaser `pixelArt: true`, у CSS `image-rendering: pixelated`.
- Розміри: тайл 16×16, героїня 16×32, портрет наставника 64×64, предмет і ворог 16×16, іконка UI 8×8.
- Файли `*-new.jpg` (і `portraits/Gemini_Generated_Image_*.jpg`) — мої нові зображення, вони **замінюють** PNG-спрайти дизайн-системи. Їх треба нарізати й підготувати для гри в розмірах вище. Якщо незрозуміло, що саме зображено на файлі, як його різати або до якого наставника, локації чи об'єкта він належить — запитай мене.
- PNG-спрайти з дизайн-системи лишаються запасним варіантом, поки нові не підготовлені.
- `images/previews/` — лише для перегляду, у гру не підключати.
