# Biomes

Палітри й тайли п'яти біомів семестру 1, кожен у своєму постійному сезоні, і п'ять стадій відродження.

- Тайл 16×16, показ ×3 або ×4 без згладжування (`image-rendering: pixelated`, у Phaser `pixelArt: true`).
- Кожен біом малюється лише своєю палітрою з 8 кольорів (`forest-*`, `tower-*`, `market-*`, `forge-*`, `library-*`) + спільні кольори героїні й інтерфейсу.
- Стадії відродження — фільтри `revival-1…5`: від майже сірого (насиченість 10 %) до повної палітри. Стадії розподіляються пропорційно кількості лабораторних.
- Мінімальний набір тайлів біому: земля, стежка, особлива поверхня (вода/крига/лава/зоряна підлога), реквізит.
