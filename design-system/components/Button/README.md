# Button

Кнопки інтерфейсу: основна, другорядна та кнопка-іконка, кожна в чотирьох станах — звичайна, під курсором, натиснута, неактивна.

**Що передати:** `<button class="dv-btn dv-btn--primary">` (або `--icon`, або без модифікатора для другорядної), текст-дієслово і за потреби `.dv-ico` перед текстом. Для кнопки-іконки обов'язковий `aria-label` / `title`.

- **Основна** (`moss-600`, текст `ink-on-accent`) — одна на панель: «Продовжити», «Виконано», «Забрати».
- **Другорядна** (пергамент `parchment-100`, рамка `wood-700`) — усе інше: «Пізніше», «Налаштування».
- **Іконка** (дерево `wood-500`) — закрити вікно, пошта, налаштування, 40×40.
- Стани: наведення світлішає і запалює дві руни `rune-glow` у кутах; натиснення знімає бортик і зсуває текст на 1 піксель вниз; неактивна — `disabled-fill` без бортика й об'єму.
- Фокус з клавіатури — обведення `wood-900` / `honey-300` / `wood-900` (див. «Стани» в `design-system/README.md`). Класи `is-hover`, `is-pressed`, `is-disabled` — для макетів.
- Не ставте дві основні кнопки поруч; не заокруглюйте кути.
