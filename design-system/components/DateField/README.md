# DateField

Поле дати виконання лабораторної; за замовчуванням — сьогодні.

**Що передати:** `.dv-field` з `label`, `input.dv-input.dv-input--date` (`type="date"`), підказкою про вчасність.

- Під полем одразу видно наслідок: «Вчасно — +монети і заряд щита знань» або «Після дедлайну — без бонусу вчасності».
- Дата оцінювання не вводиться ніде.
