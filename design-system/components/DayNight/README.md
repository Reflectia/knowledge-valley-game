# DayNight

Освітлення світу протягом дня: множник `light-*` на тайли і спрайти, вночі — теплі джерела світла.

- Ранок `light-morning` → день `light-day` → вечір `light-evening` → ніч `light-night`, плавно протягом ігрового дня.
- Вночі світять вікна (`light-window`, радіус 14), ліхтарі (`light-warm`, 20), світлячки (`light-firefly`, 3): два кільця з піксельним дизерингом, без розмитих градієнтів.
- Інтерфейс не тонується ніколи.
