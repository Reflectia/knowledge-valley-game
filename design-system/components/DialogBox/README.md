# DialogBox

Діалогове вікно внизу екрана: портрет наставника 64×64 (показ ×2), табличка з іменем і 1–2 рядки репліки.

**Що передати:** `.dv-panel.dv-dialog`, у ньому `.dv-dialog__portrait > img` (портрет), `.dv-nameplate` з іменем, `p.dv-dialog__text` і кнопки в `.dv-dialog__next`.

- Текст — стиль `body-lg` (32/40), максимум 2 рядки; довше — розбийте на кілька реплік.
- Тон: теплий, з легким гумором про навчання, інколи трохи філософський; без докорів за запізнення.
- Перехід до наступної репліки — ЛКМ по вікну або кнопка «Далі»; відповіді гравчині — другорядні кнопки.
