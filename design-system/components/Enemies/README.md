# Enemies

Вороги 16×16: три «навчальні» з гумором і по одній звичайній істоті кожного біому.

- Монстр Дедлайну (будильник), Привид Прокрастинації (сонний), Плагіатний Слиз (з чужим аркушем) — з'являються в усіх локаціях.
- Звичайні істоти малюються палітрою свого біому; боси-екзамени — 32×32.
- Вороги милі, а не страшні: великі очі, округлі силуети, кольоровий контур.
