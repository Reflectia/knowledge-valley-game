# FileUpload

Поле завантаження файлу для імпорту навчального плану (CSV, XLSX, JSON) або збереження (.json).

**Що передати:** `.dv-file` з іконкою `upload`, текстом про формати, прихованим `input type="file"` за кнопкою «Обрати файл»; під час перетягування — `is-over`.

- Поруч — кнопка «Завантажити шаблон» (CSV із заголовками).
- Після вибору файлу — попередній перегляд і помилки до застосування; нагороди не дублюються при повторному імпорті.
