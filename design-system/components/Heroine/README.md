# Heroine

Героїня 16×32 у стилі Stardew Valley: три напрямки та варіанти налаштування зовнішності.

- Кадр 16×32, ноги на нижньому краї тайла 16×16; голова займає верхні ~15 пікселів.
- Контур кольоровий: край кожної ділянки — темніший відтінок її ж кольору (волосся — темно-руде, одяг — темно-зелений), не чорний.
- Налаштування: зачіска і колір волосся (4), тон шкіри (4), колір одягу (4) — перефарбування тієї самої палітри.
- Анімація ходьби: 4 кадри на напрямок; ліво = дзеркало права.
