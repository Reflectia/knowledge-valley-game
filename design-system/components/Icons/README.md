# Icons

Набір піксельних іконок інтерфейсу 8×8, що показуються ×2 (16 px) або ×4 (32 px, `dv-ico--lg`).

**Що передати:** `<span class="dv-ico dv-ico--heart" aria-hidden="true">` поруч із текстом; самостійна іконка — у кнопці з `aria-label`.

- Контур — темніший відтінок кольору самої іконки, не чорний.
- Значки рідкісності `r-*` мають різну форму: коло, ромб, зірка, корона.
