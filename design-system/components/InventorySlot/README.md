# InventorySlot

Слот інвентарю 48×48 для однієї іконки предмета 16×16 (показ ×2): порожній, з предметом, з рамкою рідкісності, вибраний.

**Що передати:** `.dv-slot` (+ `--common|--rare|--epic|--legendary` для унікальних речей), `<img>` предмета, значок `.dv-slot__badge` з іконкою `r-*`, кількість `.dv-slot__count`; `is-selected` — активний слот панелі (клавіші 1–9).

- Рідкісність ніколи не лише колір: рамка змінює форму (1 → 2 лінії → кутові самоцвіти → потрійна з відблиском) і має значок: коло · ромб · зірка · корона.
- Звичайні ресурси (насіння, урожай) — у простому слоті без рідкісності.
- Кількість — цифри `parchment-50` з контуром `wood-900`, у правому нижньому куті.
