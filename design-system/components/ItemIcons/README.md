# ItemIcons

Іконки предметів 16×16 у чотирьох рідкісностях: зілля, посох, насіння, книга.

- Спрайт предмета однаковий; рідкісність додає рамка слота і значок, а для легендарних — золотий відблиск.
- Іконка займає 14×14 з 1 пікселем повітря; світло падає зліва зверху.
- Пороги: Легендарна 90–100 %, Епічна 75–89 %, Рідкісна 60–74 %, Звичайна < 60 % (редагуються в налаштуваннях).
