# JournalPage

Розворот книги-щоденника: дисципліна, її лабораторні зі статусом, дедлайном і діями «Виконано» / «Ввести бал».

**Що передати:** `.dv-book` з двома `.dv-page`; у сторінці — заголовок дисципліни, підзаголовок (локація · стадія) і рядки `.dv-lab` з назвою, мета-рядком (іконка + дедлайн) і статусом `.dv-chip`.

- Статус — завжди іконка + слово: «Не виконано», «Виконано 18.10», «Оцінено 9/10 · Легендарна»; запізнення — окремий чип «із запізненням» `clay-600`, без штрафних формулювань.
- «Виконано» — основна кнопка й відкриває поле дати (за замовчуванням сьогодні); «Ввести бал» — другорядна, відкриває поле балу.
- Будь-яка зміна зберігається одразу; запис можна виправити — нагорода перераховується.
- Сторінки розлінійовані з кроком 32 px (лінія `parchment-200` на 24–26 px кожного рядка). Усе на сторінці — кратне 32 px: рядки тексту 32, чип 28 + 2×2, поле й кнопки — у рядку 64, проміжок між лабораторними — 32. Тоді кожен рядок тексту «стоїть» на лінії. Не додавайте відступів, не кратних 32 px.
