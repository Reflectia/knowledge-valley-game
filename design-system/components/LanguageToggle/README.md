# LanguageToggle

Перемикач мови інтерфейсу: українська (основна) та англійська, у налаштуваннях і на стартовому екрані.

**Що передати:** дві `.dv-btn` у `.dv-lang__group` з `aria-pressed`; підписи — автонім мови (`УКР`, `ENG`), не прапори.

- Активна мова має вигляд основної кнопки, інша — другорядної.
- Перемикання миттєве, без перезапуску; назви дисциплін з імпорту не перекладаються.
