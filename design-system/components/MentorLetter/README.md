# MentorLetter

Лист наставника в поштовій скриньці: нагадування за 3 дні до дедлайну, привітання з нагородою, сюжетні листи.

**Що передати:** `.dv-letter` з печаткою `img.dv-letter__seal`, шапкою `.dv-letter__head` (від кого · дата гри), заголовком, текстом `.dv-letter__body`, підписом і діями.

- Папір `parchment-50` у світлій рамці, червона печатка `clay-600` — без дерев'яної рамки, щоб лист відрізнявся від системних вікон.
- Текст до 3 рядків `body` (24/32); дедлайн і номер лабораторної — завжди явно.
- Дії: основна «Відкрити щоденник», другорядна «Пізніше». Нагадування не сварять.
