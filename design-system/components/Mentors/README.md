# Mentors

Портрети п'яти наставників семестру 1 для діалогів — окремі спрайти 64×64, показ ×2.

- Погруддя, погляд у камеру, фон — світлий тон палітри свого біому з дизерингованим обрієм.
- Кольоровий контур, як у всіх спрайтів; очі з 1-піксельним відблиском.
- Імена та фінальний вигляд — відкрите питання ТЗ; зараз підписано ролями.
