# Panel

Вікно-панель із дерев'яною рамкою, пергаментним тлом, заголовком і кнопкою закриття — основа всіх екранів.

**Що передати:** `.dv-panel` з `h2.dv-panel__title` і кнопкою `.dv-btn.dv-btn--icon.dv-panel__close` (`aria-label="Закрити"`), далі будь-який вміст.

- Рамка — 9-slice спрайт: контур `wood-900`, брус `wood-700`/`wood-500`, фаск `wood-300`, руни `rune-glow` у кутах, внутрішня лінія `parchment-300`, тло `parchment-100`.
- Кнопка закриття сидить на правому верхньому куті рамки; Esc теж закриває.
- Панелі не змінюються вдень і вночі — освітлення діє лише на світ.
- Внутрішній відступ `space-8`; роздільники — 2 px `parchment-300`.
