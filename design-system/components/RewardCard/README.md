# RewardCard

Картка нагороди: одинична за «Оцінено» і пакетна сцена «Долина пам'ятає твої зусилля» для ретроактивної здачі.

**Що передати:** `.dv-panel.dv-reward` з кікером `.dv-reward__kicker`, великим слотом `.dv-slot--lg` (іконка ×4), назвою, рядком рідкісності зі значком, описом і основною кнопкою «Забрати»; пакетна — `.dv-reward__list` зі звичайними слотами.

- Рідкісність — рамка + значок + слово; кожна рідкісність має свій звук.
- Пакетна сцена збирає кілька нагород в одну, щоб не клацати десять разів.
