# ScoreField

Числове поле для балу лабораторної з максимумом поруч і передбаченням рідкісності.

**Що передати:** `.dv-field` з `label`, `input.dv-input.dv-input--num` (`type="number"`, `min="0"`, `max` = максимум, `step="0.5"`), текст «/ 10», підказку `.dv-field__help`; помилка — клас `is-error` і `.dv-field__error` з іконкою.

- Цифри шрифтом `stat` (Press Start 2P), вирівняні праворуч.
- Помилка формулюється по-людськи: «Бал більший за максимум (10)». Колір помилки `clay-600` + іконка, не лише рамка.
