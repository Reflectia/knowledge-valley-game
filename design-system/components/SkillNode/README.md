# SkillNode

Вузол дерева навичок (5 гілок за дисциплінами) у трьох станах: вивчено, доступно, закрито.

**Що передати:** `.dv-skill.is-learned|is-available|is-locked` з `.dv-skill__node` (іконка навички), назвою і словом стану; між вузлами — `.dv-tree__link` (`is-learned` для пройденого шляху).

- Вивчено — мох `moss-500`; доступно — мед `honey-500` і можна витратити очко; закрито — сіре і приглушена іконка.
- Стан завжди підписаний словом. Очки навичок дають лише лабораторні.
