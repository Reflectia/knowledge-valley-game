# StartMenu

Стартовий екран: статичний піксельний фон долини на золотій годині (640×360, показ ×2 при 1280×720), назва гри та п'ять кнопок.

**Що передати:** `.dv-start` з `img.dv-start__bg`, заголовком `.dv-start__logo` і меню `.dv-start__menu` з кнопками `.dv-btn--wide`; версія — `.dv-start__ver`.

- Порядок: «Продовжити» (основна, якщо є збереження; інакше основною стає «Нова гра»), «Нова гра», «Імпорт збереження», «Налаштування», «Мова».
- Фон без анімації; ліва верхня третина — спокійне небо під назву, права половина — під меню, тож головні деталі (садиба, вежа, річка) лежать ліворуч і в центрі.
- Глибина — повітряною перспективою: дальні гори бузкові й світлі, ближчі пагорби насичені, передній план — найконтрастніший.
- Керування лише мишею.
