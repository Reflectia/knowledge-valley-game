# StatBars

Шкали енергії, здоров'я та досвіду для HUD, з рядом рівнів і позначкою «стелі».

**Що передати:** `.dv-bar.dv-bar--energy|--health|--xp` з іконкою, `.dv-bar__track > .dv-bar__fill` зі `style="--value: 72%"` і числом `.dv-bar__value`; для рівня — `.dv-levels` з пунктами `is-reached` / `is-locked` і табличкою `.dv-levels__ceiling` перед першим закритим рівнем.

- Кожна шкала має іконку і число — не тільки колір.
- Коли рівень дорівнює стелі, досвід не росте: шкала досвіду отримує `is-capped` (медові смуги `bar-ceiling`), поруч — замок і підказка наставника.
- Стеля = 3 + 2 × кількість виконаних лабораторних; рівні за стелею — `is-locked`.
