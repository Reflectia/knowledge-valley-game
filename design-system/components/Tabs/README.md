# Tabs

Вкладки-закладки над панеллю для перемикання розділів одного вікна (інвентар, щоденник, навички, пошта).

**Що передати:** контейнер `.dv-tabs` прямо перед `.dv-panel`, кнопки `.dv-tab` з `role="tab"`, `aria-selected="true"` на активній; іконка + коротка назва.

- Активна вкладка — пергамент, що зливається з панеллю; неактивні — темне дерево `wood-700` з текстом `ink-on-wood` (9.0:1); під курсором текст `honey-300` (6.8:1). На `wood-500` мед не проходить AA — не світлішайте тло вкладок.
- До 5 вкладок; назва — одне слово. Гарячі клавіші I / J дублюють вкладки, але підпис їх не показує.
