# Toast

Коротке сповіщення в правому верхньому куті: новий лист, автозбереження, стеля рівня, нагадування про експорт.

**Що передати:** `.dv-toast` з іконкою і текстом; заголовок — `.dv-toast__title`.

- Дерев'яна плашка `wood-700`, заголовок `honey-300`, текст `ink-on-wood`.
- Один рядок заголовка + один рядок тексту; зникає через 4 с, не блокує гру. Важливе (дедлайн сьогодні) — лист і візит наставника, не сповіщення.
