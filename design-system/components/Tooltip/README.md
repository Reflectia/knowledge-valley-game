# Tooltip

Підказка при наведенні на предмет, навичку чи іконку HUD: назва, рідкісність, опис, джерело.

**Що передати:** `.dv-tooltip` з `.dv-tooltip__title`, рядком `.dv-tooltip__meta` (значок + назва рідкісності з класом `dv-rarity--*`), текстом і приміткою `.dv-tooltip__hint`.

- З'являється біля курсора без затримки, не перекриває сам предмет; ширина до 352 px.
- Назва рідкісності завжди словом і значком; колір тексту — токен `rarity-*` на `parchment-50`.
- Опис — 1–2 рядки з легким гумором; примітка — звідки річ (лабораторна і бал).
