# VolumeSlider

Повзунок гучності для налаштувань: загальна, музика, ефекти.

**Що передати:** `.dv-slider` з підписом і іконкою, `input.dv-range` (`type="range"`, 0–100) зі `style="--value: 70%"` (оновлюйте при `input`), значення `.dv-slider__value`.

- Повзунок — дерев'яна ручка з руною 6×10, заповнення `river-300` на доріжці `bar-track` (8.2:1; `river-600` там дає лише 2.5:1).
- Значення завжди числом у відсотках; крок 5 при прокручуванні колеса.
