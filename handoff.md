# Хендоф: доступність, імпорт плану, прилавок

Сесія 2026-11-05. Гілка `main`, 13 комітів від `c2aa70a` до `91d81ba`. Робоче дерево чисте; не закомічено лише `.claude/launch.json` (запуск dev-сервера для вбудованого браузера, див. «Відкриті питання»).

## Мета

1. Перевірити інтерфейс гри на доступність за WCAG 2.1 AA (контраст, фокус, клавіатура, підписи, розміри) і виправити все знайдене.
2. Попутні задачі власниці: дубль дисципліни «Наука» у щоденнику, дві «крамниці» на садибі, новий спрайт прилавка.

## Що зроблено

### Аудит доступності — усе закрито

Звіт: [docs/accessibility-audit.md](docs/accessibility-audit.md). Таблиця 1 — 55 пар кольорів, таблиця 2 — 24 пункти, у кінці — «Попутно знайдено й виправлено». Усі пункти мають позначку ✅.

- **Контраст** (`c12655b`). Плейсхолдер, іконки HUD на дерев'яних кнопках, обведення вибраного слота, колір тексту кнопок-іконок. Кольори не замінювались іншими, лише темніші або світліші відтінки. Нові токени: `wood-400` #9a6038 і `honey-700` #9a6a12.
- **Видимий фокус** (`95c9285`). Обведення в три лінії `wood-900` / `honey-300` / `wood-900` на `:focus-visible`; після клацання мишею його немає.
- **Вікна** (`06b7652`, доповнено в `da6e179`). Фокус переходить у вікно, Tab ходить по колу всередині, фон стає `inert`, після закриття фокус повертається на кнопку, що відкрила вікно. Якщо тієї кнопки вже немає, фокус лишається в наступному відкритому вікні.
- **Підказки з клавіатури** (`21e0b8e`). Підказка з'являється й від фокусу; перший Esc ховає лише її. Описи навичок прив'язано через `aria-describedby`.
- **HUD для зчитувача** (`ad65b8c`). Шкали й монети мають приховані підписи.
- **Space і стрілки** (`d27b29a`). Phaser через `createCursorKeys()` перехоплював ці клавіші для всієї сторінки, тож Space не натискав кнопки. Тепер після створення клавіш викликається `clearCaptures()`.
- **Обрізаний текст** (`da6e179`). Назви листів та ім'я в HUD переносяться, а не обрізаються трикрапкою; `height` → `min-height`. Перевірено зі стилями WCAG 1.4.12.
- **Решта пунктів** (`f5435ea`):
  - клавіші E / Q у світі;
  - сповіщення з дією — справжня кнопка, таймер стоїть на паузі під курсором і у фокусі;
  - вкладки за патерном ARIA Tabs;
  - функція `loc()` замість жорсткого `.uk`, `<html lang>` оновлюється;
  - HUD 24 px, кнопки-іконки 44×44, проміжок 8 px у перемикачах;
  - видимий підпис, чому вимкнено ENG;
  - `#game` з `aria-hidden`;
  - Esc закриває діалог сну біля ліжка.

## Прийняті рішення (за погодженням власниці)

1. **E / Q у світі** доповнюють ЛКМ / ПКМ (ТЗ §8).
   - E — найближче ліжко / щоденник / прилавок / пошта / наставник у досяжності, інакше інструмент на клітинці перед героїнею; зі зброєю — атака туди, куди вона дивиться.
   - Q — заклинання або поставити / забрати предмет.
2. **Числа HUD і номери слотів — 24 px.** Номери стоять у куті слота з темним контуром.
3. **Повторний імпорт** прибирає дисципліни без прогресу, яких немає у файлі (ТЗ §7, `docs/decisions.md` п. 11).
4. **Прилавок лишається** і називається «Прилавок» (`docs/decisions.md` п. 12).
5. **Тент прилавка зелено-кремовий**, щоб не плутати з червоною «Крамницею».
6. **Кольори при виправленні контрасту** лише темнішають або світлішають, нових відтінків не вигадано.
7. **У власних запусках гри** звук вимикається до першого кліку (збережено в пам'яті асистента).

## Відкриті питання

- **Дубль «Науки» в грі власниці ще є.** Він зникне після повторного імпорту `plan-semester1-new.csv` у її браузері: стара дисципліна без прогресу, тож імпорт її прибере.
- **Ліхтарик на тенті прилавка вночі не світиться.** Можна ввімкнути `lamp: true`, як у ліхтаря біля будинку, але треба перевірити, що гра знайде скло на новому спрайті.
- **Дві дисципліни з одним пакетом** матимуть однакові підписи вкладок (показується назва гілки). Повна назва є в підказці й для зчитувача, але візуально їх не розрізнити. Питання до ТЗ: чи можливі дві дисципліни на один пакет.
- **Не перевірено в грі:**
  - Q з меблями;
  - E з інструментами на городі;
  - вкладки прилавка (той самий код, що й перевірені вкладки налаштувань);
  - браузери Firefox і Edge — усі перевірки були у вбудованому Chromium.
- **Тексти листів наставників** (`src/core/mentors.ts`) лишаються українськими навіть з англійською мовою. Це стане актуально у v0.3, коли з'явиться англійська.
- **`.claude/launch.json`** не закомічено: це конфігурація dev-сервера для вбудованого браузера. Вирішити, чи додати його в репозиторій, чи в `.gitignore`.
- **Міжрядковий інтервал основного тексту 1.33** відповідає AA, але для AAA (1.4.8) потрібно 1.5. Свідомо не чіпали.

## Наступний крок

Власниці: повторно імпортувати `docs/examples/plan-semester1-new.csv` у своїй грі й переконатися, що «Наука» одна, з двома виконаними роботами.

Далі — за вибором власниці:

1. ввімкнути нічне світло ліхтарика на прилавку;
2. пройти невивірені сценарії: Q з меблями, E на городі, Firefox / Edge.

Як перевіряти:

```bash
npx tsc --noEmit -p .
```

```bash
npx vitest run
```

Очікується 139 тестів. Прилавок після заміни зображення перегенерувати:

```bash
python scripts/assets/build_buildings.py stall
```

```bash
node scripts/maps/build-maps.mjs
```
