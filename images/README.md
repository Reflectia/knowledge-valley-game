# Асети «Спадок у Долині Знань»

Усі файли, крім `previews/`, — у рідному розмірі (1 піксель = 1 піксель гри). Масштабуйте лише цілими кратними без згладжування (у Phaser `pixelArt: true`, у CSS `image-rendering: pixelated`).

- `biomes/` — усі тайли локацій, які використовує гра (16×16): `<біом>-tileset-16.png` (земля · стежка · особлива поверхня · реквізит на землі · реквізит окремо, прозорий; `scripts/assets/build_biome_tiles.py`) і `homestead-tiles-16.png` (трава · трава з квітами · стежка; `build_sprites.py homestead`). Нові тайли кладіть сюди.
- `characters/` — героїня 16×32: спереду · ззаду · збоку; варіанти волосся/шкіри/одягу.
- `portraits/` — портрети наставників 64×64 для діалогів (показ ×2).
- `items/`, `enemies/` — спрайти 16×16.
- `ui/frames/` — 9-slice рамки; число після `slice` — розмір кута в пікселях (CSS: `border-image-slice`, ширина рамки = slice × масштаб інтерфейсу).
- `ui/icons/` — іконки 8×8 (показ ×2 = 16 px); `r-*` — значки рідкісності.
- `ui/` — вузли дерева навичок 20×20, ручка повзунка, печатка листа.
- `backdrops/` — фон стартового меню 640×360 (×2 = 1280×720).
- `lighting/` — приклад садиби вдень і вночі.
- `previews/` — аркуші ×4 з дизайн-системи для перегляду, не для гри.

Стадії відродження біомів робляться фільтром у грі (токени `revival-1…5`), окремих тайлів для них немає.
